# 鲸鱼娘图集

`whale-girl-sheet.png` 沿用项目维护者选用的 AI 生成像素角色图集，按原文件复制，未重新绘制。

尺寸 1536 × 1024，4 列 × 2 行，每格 384 × 512。顺序：待机、眨眼、招呼、鼓脸、被拎起、游动一、游动二、读书。`whale-pet.js` 按脚底位置对齐各姿态；角色和命中遮罩共享同一绘制结果。

这是回看使用的角色素材，不是 DeepSeek 官方标识或官方联名。

## 动作扩展候选

`whale-girl-motions-v2.png` 使用内置 imagegen，以原图集和当前角色截图为参考生成；原图集保持不变。生成结果实际为 1254 × 1254，4 列 × 3 行透明图集，按比例读取单元。顺序：俏皮眨眼、歪头、伸懒腰、哈欠、打盹、惊讶、欢呼、比心、展示便签、读书、翻页、游动。

渲染时按脚底锚点对齐，新增姿势按 0.93 比例匹配原角色大小；最后一格的尾部略跨单元边缘，读取时从左侧空隙补足 8 个源像素，并在前一格排除该尾部像素。命中检测使用最终绘制的透明度。

控制器提供 15 组短动作。待机仍以眨眼为主，每第三次待机间隔穿插一次安静动作；悬停轮换招呼、俏皮眨眼和比心，放下轮换鼓脸、惊讶和欢呼。隐藏、展开阅读和减少动态效果时停止相应动作计时。
