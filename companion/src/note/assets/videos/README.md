# 连续鲸鱼娘动画

本地 0.3.10 候选接入 `idle.webm` 和 `stretch.webm`。原视频由豆包桌面版 Seedance 2.5 根据现有鲸鱼娘参考图生成，原始标准为 1280 × 720、24 fps。本版沿用原视频颜色和线条，不使用额外锐化。145 帧中的 123 帧经 KORYAO 驱动本机 Photoshop 建立可编辑主体蒙版，并保存重开 PSD；末段 22 帧因 Photoshop 批次超时，暂用本地绿幕抠像补齐。未验证的超时批次不参与成片。

伸懒腰约 6 秒，待机循环从开头的轻微动作截取并往返衔接，尚不是独立制作的待机动作。去除绿幕后保留透明通道，并移除音轨。该版本供实际浮窗效果检查，完整 Photoshop 批次及用户视觉验收仍待完成。

播放器读取本目录内固定名称的 WebM，使用 VP9 和 alpha、24 fps、384 × 512 画布；其他等比例 3:4 画布也可读取，单段不超过 30 秒。动作在画布中的中心、比例及鲸鱼下缘须与待机接近，开头和结尾回到待机姿势，抬手和尾巴需要留在边界内。

`whale-pet-asset.cjs` 只读取白名单中的本地文件。缺失、超限、无法解码或播放失败时使用原有图集；减少动态效果、隐藏或打开便签时停止视频。没有完成连续素材的其他动作仍使用关键姿态。

自动动作在上一次结束后等待随机 12–26 秒，按权重抽取，并避开最近两个动作。伸懒腰冷却 60 秒、读书及展示便签 75 秒、哈欠 90 秒、打盹 180 秒；眨眼和鼠标、拖动反馈独立处理。

制作时保留原 MP4、实际去绿幕参数、编码日志及来源记录；本轮对应候选工作目录的 `video-source/`。运行插件不访问生成服务。
